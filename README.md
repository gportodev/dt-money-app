## Como usar

```bash
# Clone o repositório 
$ git clone https://github.com/gportodev/dt-money-app.git

# Acesse a pasta
$ cd dt-money-app

# Instale as dependências
$ npm install

# Instale no dispositivo físico/emulador
$ npx expo run:android

# Inicie o servidor
$ npx expo start
```
